02 — Signal Processing

Vibration & Acoustic Pipelines

Production-grade signal analysis pipelines for vibration and acoustic data — from raw sensor output to actionable features for condition monitoring and system identification. 

% Vibration signal processing pipeline
function features = extract_vibration_features(signal, fs)
    % Preprocessing
    signal = detrend(signal);
    signal = bandpass(signal, [10 5000], fs);

    % Time domain
    rms = sqrt(mean(signal.^2));
    crest = max(abs(signal)) / rms;
    kurt = kurtosis(signal);

    % Frequency domain
    [pxx, f] = pwelch(signal, hanning(1024), 512, 2048, fs);
    [peak_f, peak_p] = findpeaks(pxx, f, 'MinPeakProminence', 0.1*max(pxx));

    % Envelope analysis for bearing faults
    env = abs(hilbert(signal));
    [env_pxx, env_f] = pwelch(env, hanning(1024), 512, 2048, fs);

    features = struct('rms', rms, 'crest', crest, 'kurtosis', kurt, ...
                      'peak_freq', peak_f, 'peak_power', peak_p, ...
                      'envelope_spectrum', struct('f', env_f, 'pxx', env_pxx));
end

Application: This pipeline feeds directly into the System Identification workflows below — envelope spectrum peaks map to bearing defect frequencies (BPFI, BPFO, BSF, FTF) for automated fault classification.

03 — System Identification

Grey-Box & Black-Box Modeling

Mechanical systems modeled from input-output data for surrogate validation, reduced-order modeling, and controller synthesis. Three model structures cover the spectrum from physically interpretable to purely data-driven.

Model Structure Type Use Case Validation
ARX / ARMAX Linear Parametric Weakly nonlinear regimes; physical parameter constraints Residual analysis + cross-validation
State-Space (N4SID) Subspace Identification MIMO systems; modal parameter extraction from operational data Stabilization diagrams + MAC
Nonlinear NARX Neural Network ARX Hysteresis, saturation, backlash effects FEA benchmark comparison 
% N4SID Subspace Identification - Operational Modal Analysis
function [A, C, K, x0] = identify_modal_params(u, y, fs, nx)
    % u: input (force), y: output (acceleration), fs: sample rate, nx: state order

    % Create iddata object
    data = iddata(y, u, 1/fs);
    data = detrend(data);

    % N4SID with focus on simulation
    opt = n4sidOptions('Focus', 'simulation', ...
                       'Display', 'on', ...
                       'EstimateCovariance', true);
    sys = n4sid(data, nx, opt);

    % Extract modal parameters
    [fn, damp, mode_shape] = modal(sys, fs);
    MAC = modalsys(mode_shape);

    % Stabilization diagram for order selection
    [stab, ~] = stabplot(sys);
    disp('Stabilization diagram generated for order validation.');
end
