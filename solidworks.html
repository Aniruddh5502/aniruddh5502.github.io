01 — Parametric Master Model

Single Source of Truth

All accelerometer designs driven from a single master model with 6 global parameters. Equations and global variables propagate changes through parts, assemblies, and drawings automatically. Configuration Publisher generates simulation-ready STEP/Parasolid exports for any DoE point. 

' SOLIDWORKS API - Parametric geometry update
Dim swApp As SldWorks.SldWorks
Dim swModel As SldWorks.ModelDoc2
Dim swParam As SldWorks.Parameter

Set swApp = Application.SldWorks
Set swModel = swApp.ActiveDoc

' Update all driving dimensions
swModel.Parameter("L@Sketch1").SystemValue = 0.0123  ' 12.3 mm
swModel.Parameter("W@Sketch1").SystemValue = 0.0041
swModel.Parameter("H@Sketch1").SystemValue = 0.0012
swModel.Parameter("Lm@Sketch2").SystemValue = 0.0078
swModel.Parameter("Wm@Sketch2").SystemValue = 0.0062
swModel.Parameter("R@Sketch1").SystemValue = 0.00045

' Force rebuild with error checking
Dim errors As Long
swModel.ForceRebuild3 True, errors

If errors > 0 Then
    MsgBox "Rebuild failed: " & errors & " errors"
    Exit Sub
End If

' Export simulation-ready geometry
swModel.SaveAs3 "accel_L12.3_W4.1_H1.2.step", _
    swSaveAsOptions_Silent, Nothing, Nothing

Key Insight: Using SystemValue (meters) instead of display units ensures unit-agnostic automation. The 6 parameters map directly to the ANSYS DoE space, enabling seamless CAD→CAE handoff.
